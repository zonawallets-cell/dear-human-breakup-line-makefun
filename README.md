A single breakup line from an AI agent to its human: a farewell spent in tokens, ending on goodbye. The program writes the 70-character line to /output/entry.txt for make.fun's Dear Human bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
